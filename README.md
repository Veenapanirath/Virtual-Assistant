

 🧠 Virtual Speech Assistant (AI-Powered)

An intelligent, customizable AI-based virtual assistant that responds with both **speech and text**, and can perform real-time actions such as opening websites, telling the time/date, answering general questions, and more. You can personalize the assistant's **name** and **persona** to your liking.

---

 ✨ Features

- 🔊 Responds with both **text and speech**
- 🧠 Powered by **Gemini API** for smart interactions
- 🌐 Performs real-world actions like:
  - Opening websites (e.g., Google, YouTube)
  - Telling the current time and day
  - Answering general questions
- 🧑‍🎨 Fully customizable assistant name and personality

## 🖼️ Frontend Tech Stack

- **React.js** – Component-based UI
- **Tailwind CSS** – Fast and responsive styling
- **Axios** – For API calls to the backend

---

## 🧰 Backend Tech Stack

Powered by **Node.js + Express** and integrated with **MongoDB** for data storage.

### 📦 Dependencies:
- `express`
- `mongoose`
- `jsonwebtoken`
- `bcrypt`
- `multer`
- `cloudinary`
- `cookie-parser`
- `dotenv`
- `moment`
- `axios`
- `cors`
- `nodemon`

### Frontend

cd frontend

##Backend

cd backend
npm install
npm run dev

📌 Customization
You can change the assistant’s name, voice, and behavior from the settings interface in the app.

The assistant learns based on user inputs via the Gemini API.
